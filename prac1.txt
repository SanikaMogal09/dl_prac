Q1. What is Artificial Intelligence (AI)?
Answer:

Artificial Intelligence is a branch of computer science that enables machines to perform tasks that usually require human intelligence.

For example:
- Recognizing faces in photographs.
- Understanding spoken language.
- Recommending movies.

Q2. What is Machine Learning (ML)?
Answer:

Machine Learning is a branch of AI in which computers learn patterns from data and use those patterns to make predictions.

In traditional programming, we provide the rules explicitly. In Machine Learning, we provide examples and allow the algorithm to learn patterns from them.

Example:

Suppose we want a computer to recognize handwritten digit 5.

Instead of manually writing every rule describing the shape of the digit 5, we provide thousands of images of handwritten digits along with their correct labels.

The computer learns patterns from these examples.

Later, when we give it a new handwritten digit, it predicts which digit it represents.
Q3. What is Deep Learning (DL)?
Answer:

Deep Learning is a subset of Machine Learning that uses artificial neural networks with multiple layers to learn patterns from data.

Think of it like this:
- AI: The broad field of making machines intelligent.
- ML: A way for machines to learn from data.
- DL: A way of learning using neural networks with multiple layers.
Deep Learning is particularly useful for images, speech, text, and other complex data.
Q4. What is an Artificial Neural Network (ANN)?
Answer:

An Artificial Neural Network is a computing model inspired by the way biological neurons process information.

It consists of interconnected units called neurons, arranged into layers.

A simple neural network has three types of layers:
1. Input layer: Receives the input data.
2. Hidden layer: Learns useful patterns from the input.
3. Output layer: Produces the final prediction.
For your experiment, imagine providing an image of a handwritten 7.
- The input layer receives the image's pixel values.
- The hidden layer learns patterns such as edges, lines, and shapes.
- The output layer estimates which digit the image represents.
The network learns by adjusting its internal numerical values during training.
Q5. What is a Feedforward Neural Network?
Answer:

A Feedforward Neural Network is an artificial neural network in which information moves in one direction: from the input layer, through the hidden layers, to the output layer.

There are no feedback connections carrying the output back into earlier layers as part of the network's forward path.

Your experiment uses a feedforward neural network with one hidden layer.

The architecture is:

Input image → Flatten layer → Hidden layer → Output layer

Q26. What is loss?
Answer:

Loss is a numerical measure of how incorrect the model's predictions are according to a specified loss function.

Generally, a lower loss indicates better predictions, although loss must be interpreted alongside other measures.

For example:
- Higher loss: The predictions may be far from the desired results.
- Lower loss: The predictions generally agree better with the correct labels.
Loss is not the same as accuracy.

A model can classify many images correctly but still have a relatively high loss if its predicted probabilities are poor.

- Sparse: The correct labels are represented as integers.
- Categorical: The task involves choosing among multiple classes.
- Cross-entropy: A loss function that measures how well the predicted probability distribution agrees with the correct class.
Our dataset has 10 classes, representing digits 0 through 9.

The labels are integers, such as:
0, 3, 7, 9, 2

We do not need to convert each label into a one-hot encoded vector for this loss function.

For example, the label for digit 7 is simply:

Viva question: Why do we use sparse categorical cross-entropy?

We use it because this is a multiclass classification problem with integer-encoded labels.

Important: If we used one-hot encoded labels instead, categorical_crossentropy would generally be the appropriate counterpart.
