Q1. What is Machine Learning?
Answer:

Machine Learning is a branch of Artificial Intelligence (AI) that enables computers to learn patterns from data and make predictions without being explicitly programmed with every rule.
Example
Suppose we give a computer thousands of pictures of cats and dogs.
- Initially, the computer doesn't know the difference.
- We train it using pictures.
- It learns patterns from those pictures.
- Later, when we give it a new picture, it predicts whether it contains a cat or a dog.
This process is called Machine Learning.

Think of a neural network as a system that learns by adjusting numerical values called weights.

For example, a neural network can learn to:
- Recognize images.
- Understand human language.
- Recognize speech.
- Make predictions.

Q4. What is CBOW?
Answer:

CBOW stands for Continuous Bag of Words.

It is a Word2Vec model architecture that learns word representations by predicting a target word from its surrounding context words.

In simple language, the model looks at the words around a missing word and tries to guess the missing word.
Example
Consider this sentence:
Deep learning is powerful.

Suppose the word is is missing.

The surrounding words might be:
- Deep
- learning
- powerful
The CBOW model uses the context words to predict the missing word.

Conceptually:

Input: Context words
Processing: Neural network
Output: Predicted target word

Your practical uses this same idea, although it uses a small custom dataset instead of a large language corpus.

Q7. What is Word2Vec?
Answer:

Word2Vec is a technique for learning numerical representations of words from their surrounding words.

These numerical representations are called word embeddings.

Word2Vec has two famous architectures:
1. CBOW: Predicts a target word from surrounding words.
2. Skip-gram: Predicts surrounding words from a target word.
The difference is important for viva examinations.
CBOW	Skip-gram
Context words are inputs.	Target word is the input.
Predicts the target word.	Predicts surrounding words.
Usually efficient for frequent words.	Can work well for less frequent words.

Q24. Explain the Lambda layer.
Your code:
model.add(Lambda(lambda x: tf.reduce_mean(x, axis=1)))


Answer:

The Lambda layer applies a custom operation to the output of the previous layer.

In your model, it calculates the average of the four context-word embeddings.

Let's understand this step by step.

Suppose the embedding layer generates four vectors:
Word 1: [1, 2]
Word 2: [3, 4]
Word 3: [5, 6]
Word 4: [7, 8]

These numbers are just an example using two-dimensional vectors for easy understanding.

The Lambda layer calculates the average:
\[
\text{Average}=\frac{\text{Vector 1}+\text{Vector 2}+\text{Vector 3}+\text{Vector 4}}{4}
\]
The result is:
[4, 5]

Instead of passing four separate vectors to the next layer, the model passes one averaged vector.
What does tf.reduce_mean() do?
It calculates the mean, or average, of values along a specified dimension.
What does axis=1 mean?
For the embedded input shape:
(batch_size, 4, 10)

axis=1 refers to the four context positions.

The average is calculated across those four positions, producing:
(batch_size, 10)

Viva question: Why do we average the embeddings?

CBOW combines the representations of the surrounding words into one context representation, which the model uses to predict the target word.

Viva question: Why is the model called a Bag of Words?

In this implementation, averaging the context embeddings removes their positional order from the combined representation. The model uses the collection of context words to predict the target rather than preserving the order of those words in that averaged vector.
